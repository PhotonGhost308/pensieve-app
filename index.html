Install on iPhone & iPad安装到 iPhone 与 iPad

This IPA is unsigned. It needs your own Apple ID signing through a computer; Safari cannot install it directly. It is not an App Store or TestFlight release.这是未签名 IPA，需要通过电脑用你自己的 Apple ID 签名；不能直接在 Safari 中点击安装，目前不是 App Store 或 TestFlight 版本。

  1. On your Mac or Windows PC, download the IPA and install Sideloadly from its official website (or use AltStore).在 Mac 或 Windows 电脑上下载 IPA，从官网安装 Sideloadly（也可使用 AltStore）。
  2. Connect your device by USB and tap Trust. Open the IPA in Sideloadly, select the device and follow its Apple ID signing instructions. Never enter Apple credentials on this website or GitHub.用 USB 连接手机并点击“信任”。在 Sideloadly 中选择 IPA 和设备，按其说明使用 Apple ID 签名安装。不要在本网页或 GitHub 输入 Apple 账号密码。
  3. If prompted, trust the developer profile in Settings → General → VPN & Device Management. On iOS 16+, enable Developer Mode in Settings → Privacy & Security and restart when requested.按提示到“设置 → 通用 → VPN 与设备管理”信任开发者；iOS 16 及以上可能需要在“设置 → 隐私与安全性”开启“开发者模式”并重启。
  4. Open Pensieve. Allow microphone, local network and notifications as needed. To sync, keep your computer's Pensieve open and pair under Settings → Sync server on the same Wi-Fi.打开 Pensieve，按需要允许麦克风、本地网络和通知权限。同步时保持电脑上的 Pensieve 运行，在同一 Wi-Fi 下通过“设置 → 同步服务器”配对。

Free Apple ID signing normally needs refreshing every 7 days. Keep Pensieve open while recording; desktop integrations require your computer. This initial iOS build has not yet been tested on a physical iPhone.免费 Apple ID 签名通常每 7 天需要刷新。录音时请保持应用在前台；桌面集成功能需要电脑。本次 iOS 初版尚未经过实体 iPhone 测试。
